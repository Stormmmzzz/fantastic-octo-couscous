BUDGIT — VS CODE PROJECT

Files:
- index.html: website structure
- style.css: styles and layout
- script.js: app behavior and logic

To run:
1. Extract this folder if downloaded as a ZIP.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension and click Go Live.

The app stores data in this browser using localStorage. Files attached to subscriptions are stored in the browser's IndexedDB on this device only. Keep all three files in the same folder. The Google Fonts import needs an internet connection; system fonts are used as fallbacks.
